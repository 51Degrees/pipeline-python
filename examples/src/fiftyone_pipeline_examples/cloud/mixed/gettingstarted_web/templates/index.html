Combined device detection and IP intelligence example

This example demonstrates the use of the Pipeline API to perform both device detection and IP intelligence lookups within a single Flask web project. It highlights device detection using User-Agent and Client Hints, IP-based geolocation and network information, country names translated by the cloud service, and client-side evidence collection for enhanced detection, with one request to the cloud service returning every result.
